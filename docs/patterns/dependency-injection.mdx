# Dependency injection and logging

Actors usually need services: a repository, an HTTP client, a clock. Nixie builds actors through the same `IServiceProvider` that the rest of your application uses, so an actor declares its dependencies in its constructor like any other class. You do not need a separate hosting model.

Pass an `IServiceProvider` to the actor system to resolve constructor dependencies:

```csharp
using Microsoft.Extensions.DependencyInjection;
using Nixie;

IServiceCollection services = new ServiceCollection();
services.AddSingleton<IClock, SystemClock>();

using ServiceProvider provider = services.BuildServiceProvider();
using ActorSystem system = new(provider);

IActorRef<JobActor, RunJob> jobs = system.Spawn<JobActor, RunJob>();
```

Nixie can combine a typed actor context, registered services, and extra arguments passed to `Spawn`.

## Logging

```csharp
using ILoggerFactory loggerFactory = LoggerFactory.Create(builder =>
    builder.AddConsole());

using ActorSystem system = new(
    logger: loggerFactory.CreateLogger("Nixie"));
```

Actors that request a context can access the same logger through `context.Logger`.

Pass a logger in production. Nixie reports exceptions thrown by `Receive` only through this logger. See [Behavior and guarantees](../actors/behavior#errors-in-a-handler).
