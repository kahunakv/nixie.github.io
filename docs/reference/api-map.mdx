# API map

Use this page to find the right interface and method. Each row links the need to the API that serves it.

| Need | Interface | Spawn |
| --- | --- | --- |
| Class request, no reply | `IActor<TRequest>` | `Spawn` / `SpawnWithOptions` |
| Class request and reply | `IActor<TRequest, TResponse>` | `Spawn` / `SpawnWithOptions` |
| Struct request, no reply | `IActorStruct<TRequest>` | `SpawnStruct` / `SpawnStructWithOptions` |
| Struct request and reply | `IActorStruct<TRequest, TResponse>` | `SpawnStruct` / `SpawnStructWithOptions` |
| Batched requests | `IActorAggregate<TRequest>` | `SpawnAggregate` / `SpawnAggregateWithOptions` |
| Batched requests and replies | `IActorAggregate<TRequest, TResponse>` | `SpawnAggregate` / `SpawnAggregateWithOptions` |

## Reference operations

| Operation | Available on | Meaning |
| --- | --- | --- |
| `Send(message[, sender])` | All actors | Fire and forget. |
| `Ask(message[, sender][, timeout][, cancellationToken])` | Reply actors | Enqueue and await a typed reply. |
| `TrySend(message[, sender])` | Reply actors | Return whether a bounded actor admitted the message. |
| `TryAsk(message[, sender], out reply)` | Reply actors | Check admission before allocating reply state. |

Not every combination of the optional `Ask` arguments has an overload. Your IDE shows the exact list.

## Actor system operations

| Area | APIs |
| --- | --- |
| Creation | `Spawn*`, `Spawn*WithOptions` |
| Lookup | `Get`, `GetStruct` |
| Lifecycle | `Shutdown*`, `GracefulShutdown*`, `GracefulShutdownAll`, `Wait` |
| Scheduling | `ScheduleOnce*`, `StartPeriodicTimer*`, `StopPeriodicTimer`, `StopAllTimers`, `ScheduleShutdown` |
| Routing | `CreateRoundRobinRouter*`, `CreateConsistentHashRouter*`, `CreateBalancingRouter` |

## Exceptions

| Exception | Thrown when |
| --- | --- |
| `ActorBusyException` | A bounded inbox is full. Safe to retry. |
| `AskTimeoutException` | An `Ask` with a timeout received no reply in time. |
| `NixieException` | The API is used incorrectly. Examples: a duplicate actor name, a duplicate timer name, or a router with no routees. |

The [source repository](https://github.com/kahunakv/nixie) is the definitive API reference for overloads and generic constraints.
